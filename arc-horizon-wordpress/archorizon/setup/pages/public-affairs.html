Information & public affairs

Public Affairs

Give the public information function an accountable workspace. Prepare releases, record what has been shared, and watch for claims that need correction.

In this workspace

What the section handles.

Release editor

Draft public statements and press releases with the incident’s current facts.

Letterhead

Apply the organization’s release format for a consistent outward-facing document.

Misinformation tracker

Record a questionable claim, where it appeared, and the response or correction.

Coordination

Link public messaging to command approval and the current situation picture.

In practice

From input to action.

The workspace shares its records with related areas of the incident, so an update can inform the next task or decision.

  1. VerifyCheck the information against incident records and command direction.
  2. PublishPrepare and issue an approved statement.
  3. MonitorTrack public reaction and correct consequential misinformation.
